# Enterprise Control Console

The Vue application renders authoritative BFF views and exposes only governed admin intents. It never dumps authoritative payloads, marks tasks complete, promotes policy, activates packs, or hides partial service failure locally. Tenant, organization, project, integration, quota, cost and API-key client contracts mirror `schemas/openapi/control-plane-v1.yaml`; API-key secrets must be shown once and never persisted by the browser. Every intent digest binds the operation, resource, tenant, requester, approvals, timestamp, reason and governed payload; the Java API recomputes the same canonical binding before calling PEP. The production build requires an absolute HTTPS `VITE_CONTROL_API_URL` without embedded credentials and fails during Vite configuration when it is absent or unsafe; tenant and subject context are injected by the authenticated server shell, while CSRF uses the secure `XSRF-TOKEN` cookie.
