# Tool authoring

Declare exact SemVer, closed input/output schemas, EffectClass, RiskLevel, immutable implementation digest, executor/credential/approval/network/filesystem profiles, timeout/output limits, and compensation or irreversible rationale. PURE tools cannot request write credentials. COMPENSATABLE tools require an existing binding. IRREVERSIBLE tools require HIGH/CRITICAL risk and explicit approval. Validate, sign, and activate through the management listener.
