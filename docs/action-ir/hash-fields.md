# Action hash fields

The SHA-256 material includes schema version, task/step, agent identity, intent and goal hash, exact tool version, typed payload, resource/environment/current version, risk/data context, expected outcome, credential-reference constraints, and restricted extensions. It excludes action/request transport IDs, receive latency, connection metadata, and server logging timestamps. Any semantic mutation invalidates decisions, approvals, leases, ledger records, and evidence links.
