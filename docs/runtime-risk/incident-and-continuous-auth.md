# Runtime risk, continuous authorization, and incidents

Deterministic Rust rules own high-confidence blocking. Python semantic/statistical scoring is supplemental and can request continuous authorization only. The aggregator may narrow a lease, pause new tools, revoke credentials, or request a supervisor kill; every response carries reason and evidence digests.

Incidents deduplicate alert storms by tenant correlation key. Containment requires supervisor acknowledgement, credential revocation, task isolation, and evidence freeze. Logical replay has zero effects; sandbox replay accepts only sandbox credentials; live replay requires a fresh scoped lease and fresh approval.

Recovery requires a linked root cause, remediation change, regression test, policy/pack references, and closure evidence. A Batch 22 Release Certificate is an engine result and cannot serve as the final Batch 36 Production Closure Certificate.
