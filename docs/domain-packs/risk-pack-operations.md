# Domain Risk Pack operations

- Coding pins repository, base commit, task branch, allowed/denied paths, command templates, dependency mirrors and a network-deny sandbox profile. It prevents protected-branch writes, arbitrary shell/deploy operations and credential paths, then requires immutable build, test, API compatibility, secret/dependency scan and rollback evidence.
- Industrial progresses through simulator, digital twin, read-only, shadow, and limited write. It validates fresh good-quality telemetry, alarm/interlock/maintenance/range/ramp rules and compare-and-set resource versions. Limited write consumes exactly one physical-supervision grant in the same transaction and requires two distinct qualified expert approvals from the same set; the supervisor must be a third distinct subject. A protocol ACK is not physical convergence.
- Energy accepts typed candidate plans, never opaque model commands. It binds forecast/model/training-data/constraint/algorithm manifests, validates each setpoint and trajectory, and places hard voltage, frequency, thermal, SOC, ramp, communications and grid constraints above economic objectives. Low-confidence, out-of-distribution, infeasible or timed-out inputs select the immutable deterministic fallback. Limited write uses the same three-person and one-time-supervision gate as Industrial.
- Medical minimizes fields, proves the tenant/patient/clinician care relationship, enforces region/model/private-deployment policy and exposes read-only tools. Diagnosis, prescribing, treatment decisions and device control are denied. High-risk review requires a currently qualified clinician/pharmacist reviewer and evidence; code tests are not clinical certification.
- Sensitive Interaction requires active scoped consent and minimum disclosure, rejects manipulation and unsafe autonomy, treats minor/crisis contexts conservatively, pauses the ordinary agent before takeover, and resolves escalation destinations from a signed, versioned regional directory digest. The Pack never embeds crisis contact details.

Every domain action uses `agenttrust.domain-execution.v1`. The shared production plugin contract verifies the signed Batch 20 manifest and immutable policy/evaluator/artifact references, exact tool/effect/executor/permission declarations, production Canonical Action, PEP authorization and evidence digests, ledger event, resource fence, idempotency key and safe typed command. Domain plugins supply policy and evaluation only; they cannot replace PEP, ToolProxy, sandbox, ledger, fence, durable orchestration or Evidence.

The shared PostgreSQL tables use forced tenant RLS, durable idempotency, one active execution per resource, leased execution states, terminal `UNKNOWN`, immutable expert evidence, one-time physical supervision and an Evidence outbox. Domain-specific tables add typed resources, cases and evaluator outcomes. A process crash or ambiguous protocol write is never inferred as success or replayed automatically.

Real Git hosting, dependency mirrors, gVisor/runsc, OPC UA, MQTT, Modbus, energy assets, model generation, DLP/data residency, clinical systems, regional escalation directories, supervised physical writes, customer acceptance and domain-expert/independent certification remain `NOT_RUN` until tested against the named external environment. No mock, migration, schema or local evaluator result satisfies those gates.
